# AgentOne can now use the apps on your computer

Until now, AgentOne could only work with your files, the terminal, and the web. With **Computer Use**, it can also see and use the other apps on your computer, like a person at the keyboard. Ask it to fill in a form, click through a settings screen, or pull information out of a window, and it will find the app, read what's on screen, and act on it.

- **Two new tools.** **See apps** finds your open and installed apps and reads what's on screen in them, optionally with a screenshot. **Use apps** opens apps and clicks, types, presses keys, scrolls, and drags in them.
- **You're in control.** Both tools ask for your approval by default. You can change this, turn off screenshots, or disable the tools in the new Computer Use section of [Tools settings](/settings#section-tools).
- **Permissions in one place on macOS.** AgentOne needs Accessibility and Screen Recording access to use other apps. Check and grant both from [Computer use permissions](/settings#setting-computer-use-permissions). You may need to restart AgentOne after allowing Screen Recording.

> Note: Computer Use works on macOS and Windows for now. It isn't available on Linux yet.

# Diagrams and alerts in responses

- **Mermaid diagrams.** When AgentOne writes a Mermaid code block, it now shows up as a diagram. A "Generating diagram" placeholder appears while the code is still being written, and you can switch back to the code at any time.
- **GitHub-style alerts.** Blockquote alerts like `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, and `> [!CAUTION]` now show up as styled callouts with an icon.
- **HTML previews wait for the code.** Previewing an HTML code block while it's still being written now shows a "Generating preview" placeholder instead of a half-finished page.

# Performance

This release includes another round of work on how responses are rendered, especially in long chats:

- Long code blocks are now highlighted line by line, which makes them over 100x faster in some cases.
- Markdown in responses is rendered with a new, faster engine that uses less memory.

# Miscellaneous Changes

- Clicking a notification now brings AgentOne back up when it's minimized on macOS.
- Fixed AgentOne crashing on startup on Linux when no Secret Service keyring is available. Your API keys are stored in a local file instead, and moved to the keyring once one is available.
- The Chat History tools now leave out tool calls when reading past chats, so AgentOne reads just the conversation. It can still include them when it needs to.
- Fixed tool errors showing a provider name in front of them by mistake.
- Fixed custom styles on tables in responses being overwritten.
- The macOS installer has a new look.
- The Snap package now uses a newer base.
- Updated app dependencies.
