# Highlights

- **New:** We have a new logo and app startup screen!
- **New:** Full theme customization is _finally_ here! In addition to changing the UI's primary color, you can now change the tint color and its strength, which gives you significant control over the UI's appearance.
- **New:** Added streamed subagents with expandable nested progress, concurrent runs, and approval-aware tool execution.

- Fixed a bug when installing extensions from Smithery.
- Updated the splash screen on startup.
- Usage analytics now default to associating events with your signed-in AgentOne account ID in Google Analytics. You can change this in Settings > Help & Updates > Usage Analytics.
