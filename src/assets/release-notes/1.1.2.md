# Long chats can keep going with Compaction

Every AI model has a limited **context window**, which is how much of a conversation it can see at once. Until now, a long enough chat would eventually hit that limit and stop working. AgentOne can now **compact** the conversation: it writes a detailed summary of everything so far, then continues from that summary with a fresh context window.

- **Auto-Compact is on by default.** When a chat uses 90% of the model's context window, AgentOne compacts it automatically. This also works in the middle of a response, so long tasks with lots of tool calls can keep running instead of failing partway through.
- **You're in control.** Open the model configuration next to the model selector to turn Auto-Compact off, change the threshold (anywhere from 5% to 95%), or click **Compact now** to compact right away.
- **See what was kept.** Compacted chats show a "Conversation compacted" divider. Click it to read the summary AgentOne is working from. Your earlier messages stay visible in the chat; only the AI's view of them is replaced. If you edit or regenerate a message from before the divider, the compaction is undone and the full history comes back.
- **Recovers if summarizing fails.** If AgentOne can't write a summary during a response, it uses the new Chat History tools (below) to read back through the chat and pick up where it left off, or asks you for the context it needs.

> Note: You can't compact while AgentOne is responding or while a tool is waiting for your approval.

# AgentOne can now read your past chats

The new **Chat History** tools let AgentOne search your past conversations by keyword and read through them. Ask things like "What did we decide about the trip last week?" or "Pick up where we left off in the database chat," and AgentOne can find the chat and read the parts it needs.

- Both tools ask for your approval by default, and the approval card links to the chat AgentOne wants to read. You can change this or turn the tools off in [Tools settings](/settings#section-tools).
- Reasoning is left out and attachments are summarized, so AgentOne reads only the conversation itself.
- Dragging a chat from the sidebar into the message box now attaches a lightweight reference instead of the whole conversation. AgentOne reads what it needs from the chat with the Chat History tools, which keeps the context window free for your actual work.

# Settings, rebuilt and searchable

Settings has been rebuilt from the ground up. It's now **one scrollable page** with an "On this page" sidebar that follows along as you scroll, so you can see every setting without clicking through tabs.

- **Search every setting.** Press **Cmd/Ctrl + K** on the settings page (customizable in [Keyboard Shortcuts](/settings#section-keyboard-shortcuts)) to search. Search understands synonyms, so "dark mode," "night mode," and "color scheme" all find the Theme setting. Choosing a result scrolls to it and briefly highlights it.
- **Reorganized sections** with shorter, clearer card names.
- **Number fields behave better.** They no longer jump back to a default value while you're typing. Out-of-range values are corrected when you leave the field.
- **Provider model lists show every model.** Each provider's settings now list all of its built-in models, not just the ones you've added. You can override any built-in model's details right from the list. Overridden and custom models get a badge, and adding a model now opens its own dialog.
- **Clearer credit details.** The Account section now makes it clear that credits refresh monthly. It shows **Monthly credits used**, when your credits reset, and when a trial ends or a canceled plan stops. Signing out from the Account section now shows a loading spinner.
- Settings links in older release notes now point to the right place on the new page.
- The settings AgentOne can read and change for you now come from the same source as the settings page, so they always stay in sync.

# A new first-run experience

- **Redesigned onboarding.** Signing in now comes first. If you sign in, AgentOne uses the name on your account and skips asking for it. If you'd rather use your own API keys, choose "I want to use my own API keys instead" to set up built-in, local, or custom providers. Onboarding ends with a personal greeting.
- **Guided tour.** New users can take a quick tour that highlights the message box, attachments, the model selector, your chats, and the account menu, and ends with a few tips. You can take it again anytime from [Help & Updates](/settings#setting-help).
- **Onboarding reminder.** If you skip onboarding, a reminder offers to take you back to it. Choose **Never** to stop seeing it.

- **Click a notification to open its chat.** Clicking an AgentOne notification brings the app to the front and takes you straight to the chat it's about.

# Tools, subagents, and safety

- **YOLO mode warning.** Switching tool behavior to YOLO now explains what it means (AgentOne will edit files, run commands, and change settings without asking) and asks you to confirm. Check "Don't show this again" to skip it, or turn the warning back on in [Tools settings](/settings#setting-confirm-yolo-mode).
- **Subagents start fresh.** Subagents no longer receive the entire parent conversation. AgentOne now gives them a complete, self-contained task, which saves tokens and keeps them focused. AgentOne can also give a subagent more steps for long tasks.
- Fixed subagents occasionally not receiving their task.
- A subagent's result now comes from its final answer instead of mixing in text from earlier steps.
- Fixed the subagent spinner continuing to spin after the chat stopped.
- When a response fails with an error, any tools that were still running are now marked as interrupted instead of appearing stuck.

# Scheduled Agents

- **Late runs are skipped.** If your computer was asleep or AgentOne was closed when a scheduled agent was due, the run is now skipped if it would start more than 5 minutes late. You can change the cutoff or choose "Never skip late runs" for each agent on the [Scheduled Agents](/scheduled-agents) page, or ask AgentOne to change it. This also applies to your existing scheduled agents.
- **No more PowerShell windows on Windows.** Scheduled agents no longer flash a PowerShell window when they run.

# Appearance

- **Custom fonts.** Upload your own font files (you can add several at once) and pick them from the new font menu in [Appearance settings](/settings#setting-font). Custom fonts are stored on each device and don't sync.
- **Roboto has been removed** as a built-in font. If you were using it, AgentOne switches back to the default font.
- **Sky is the new default primary color.** The previous default is still available as **Neutral** in [Appearance settings](/settings#setting-primary-color).
- Loading spinners and the settings sidebar use more neutral colors so they don't clash with your primary color.

# Performance

This release includes a large round of performance work, especially for long chats and streaming responses:

- Saving a chat no longer re-renders most of the app, and opening a chat no longer rewrites it to disk. Just viewing a chat also no longer moves it up when sorting by **Recently active first**.
- Streaming Markdown only re-processes the part of the message that's still changing, and code highlighting is cached and throttled.
- The model catalog uses much less memory by only creating models when they're actually used.
- Typing in the message box is lighter: drafts are saved after a short pause instead of on every keystroke, and the editor no longer reconfigures itself on every update.
- Subagent and terminal tool updates are throttled, and their live data is cleaned up once they finish.
- Sidebar status indicators only update the chat that changed.
- Web search parses results faster, and secure key storage reuses a single database connection.

# Miscellaneous Changes

- Fixed commands and local extensions failing to find programs installed by tools like Homebrew or nvm in packaged builds.
- The updater now shows real download progress instead of an estimate.
- Detailed logging is now off by default in release builds, which reduces disk writes. Advanced users can set the `AGENT_ONE_LOG_LEVEL` environment variable to change it.
- Errors that were previously ignored silently are now logged, making issues easier to diagnose.
- Search inputs no longer autocorrect or autocapitalize what you type.
- Updated AI SDK, Tauri, and other dependencies.
