# Highlights

- **Fresh extensions without an app update.** The extension list now downloads separately from the app and refreshes automatically every 24 hours, including while AgentOne stays open. Downloaded lists are saved on your device so you can browse them again without downloading them each time.
- **A lighter app and a better extension browser.** We removed the large bundled model and extension lists. Extensions now load as you browse and search, and updates download only what's changed after the initial download. You can update either list manually in [Help & Updates](/settings?tab=about), with progress and error details for extension list updates.
- **More useful chat sorting.** The sidebar now defaults to **Recently messaged first**, which brings a chat to the top when you send a message. You can also choose **Recently active first** to include activity like opening a chat or changing its settings, or keep **Newest chats first** in the [Chat Settings](/settings?tab=chats#setting-chat-sort-order).
- **Extensions now stay on your device.** Installed extensions and their configuration no longer sync between devices. Your existing local extensions are kept, and you can manage each device's extensions separately.
- **Easier provider configuration.** Built-in, local, and custom providers now open their settings in a dedicated dialog. Click a provider's name or settings button in [Providers settings](/settings?tab=providers) to manage its connection and models, while keeping enable switches accessible in the list.

# Miscellaneous Changes

- Updated the text-to-speech model lists and defaults, including Gemini 3.8. If you were using Google for text-to-speech, select your voice model again in [Providers settings](/settings?tab=providers).
- Removed LMNT as a text-to-speech provider because the service has shut down. If you were using LMNT, choose another provider in [Providers settings](/settings?tab=providers).
- API key fields now include the show/hide control inside the field and display labeled **Save** and **Revert** buttons only when you have unsaved changes. Custom HTTP header editors also have clearer save and revert button styles.
- Fixed built-in password and autofill controls overlapping the app's show/hide button.
- Further reduced the app bundle size by removing React Scan and sharing the OpenAI-compatible integration for Venice and AIHubMix.
- Updated app dependencies and React build tooling.
- Chat titles now show your configured fallback while the AI title is generating, and keep it if generation fails.
- Errors from third-party AI providers now include the provider's name, making it easier to tell where an issue came from.
- Added clearer loading states and download links when the model or extension list isn't available yet.
- Extension list downloads can resume after an interruption and recover from expired page cursors.
- Newly installed extensions now keep their descriptions, icons, and other details locally so they're available even if the extension list hasn't loaded.
- Fixed sidebar time groups and chat ordering to follow your selected sort option consistently.
- Fixed icon colors in scheduled agent tool approval screens.
- Improved compatibility with changes to the billing API so account plan and credit details continue to display correctly.
- The app now uses whole numbers for billing details in the UI.
