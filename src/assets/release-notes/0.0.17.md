# Highlights

- Fixed a bug where the built-in file tools couldn't access files or directories beginning with `.`.

# Miscellaneous Changes

- File operations now support home directory shortcuts in file paths.
- Creating files automatically generates missing parent directories.
- Reworked how commands are started, streamed, and stopped for more reliable execution and clearer termination behavior. This improves the experience of extensions, MCP servers, and the terminal tool.
