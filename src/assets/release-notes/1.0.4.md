# Highlights

- We've added a **Message Preview Rail** that shows message previews and lets you jump to any message in a chat. You can enable or disable it in the [Chat Settings](/settings?tab=chats#setting-show-message-preview-rail).
- **MCP Apps support is finally here!** Support for MCP apps is now in beta. Extensions can render interactive apps directly inside your chats. MCP apps can be displayed inline, in fullscreen, or in a picture-in-picture window, and come with dynamic theme support so they blend in with the rest of AgentOne.
- **Apple support** is finally first-class. You can now use AgentOne on your Mac without having to disable security features.
- **YOLO** mode is now available! You can _dangerously_ bypass all tool approval checks in the config button next to the model name for your chats. You can also disable tools altogether, or require approval for every single tool.
- The model selector now allows you to **filter models by supported features** like reasoning, attachments, tool calling, and more. Additionally, you can see what features each model supports by looking at the badges next to the model name.

# Miscellaneous Changes

- We upgraded our backend to `rmcp` **3**, so you'll get the latest features and security improvements in the MCP standard.
- We fixed a bug affecting some of our version releases that caused update checks to fail.
- If you receive a credit grant, you'll no longer see a negative balance in the UI like before.
- There are now almost 20,000 built-in extensions.
- Responses from AgentOne are now always the full width of the chat area, using the space in the UI effectively.
- Sometimes the "Scroll to Bottom" button would appear when there was no need for it. This has been fixed.
- We fixed a bug with the sidebar controls on narrow screens.
- We disabled code syntax highlighting in "Reasoning" sections of AgentOne's responses to improve performance.
- Nearly 9000 AI models are now supported out of the box.
- Updated internal dependencies.
- Improved performance of some Rust code used in the backend.
- Codeblock headers were having issues in virtualized chats, which is now fixed.
- Very short user messages were often just as wide as the action row, which didn't look natural. We've addressed this so that short user messages take only as much space as necessary.
- Save and cancel buttons in the "Advanced" section of extensions are now stuck to the bottom of the dialog rather than the scrollable area.
- We fixed the shimmer effect on the "Working" text not appearing in dark mode. A bug where the shimmer speed changed at random was also addressed.
- Tool approval UIs from extensions previously had "Parameter" accordions that could expand to be wider than the chat area, which is now fixed.
- Fixed a bug where sending a new message didn't scroll to the bottom of the chat area.
- The "Model List Updates" section moved to [Help & Updates](/settings?tab=about).
- If you click a link to a setting larger than the viewport, the app now scrolls to the top rather than the center.
- Fixed a UI width bug in the terminal tool.
- Models that don't support tool calling are now usable within AgentOne thanks to the YOLO mode changes!
- The settings page now uses a full page scroll, removing the need for some custom hacks we were using. This improves performance and also fixes some UI bugs related to clipping.
- The setting link effect now uses the correct border radius for setting cards.
- We removed some outdated code from our codebase.
- You can now restart extensions.
- Extension login/connection prompts have been improved. If you change or disable an extension with an active login prompt, it will be dismissed automatically.
