# 🎉 AgentOne 1.0 is here

AgentOne is officially out of beta. Thank you for testing early builds, sharing feedback, and helping shape the first stable release.

# Highlights

- **AgentOne 1.0:** The beta era is over, and this release marks the first stable milestone for AgentOne.
- **Synchronization is now enabled by default** for signed-in users, with a smoother sync experience. As part of the transition out of beta, your synced settings have been reset.
- **New:** There are now over 10,000 built-in extensions!
- **Read more:** Follow launch updates, tutorials, and release stories on the [AgentOne Blog](https://blog.agent-one.dev/).
