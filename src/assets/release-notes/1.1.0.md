# ⏰ Scheduled Agents are here!

Tell AgentOne what you'd like done regularly, and it can set up a **Scheduled Agent** for you. Ask it to prepare a daily briefing, check in on a project every week, or run any other repeatable prompt on your schedule. When it's time, your computer's scheduler opens AgentOne to run the task, and **each run gets its own chat** so you can review the result.

Find [Scheduled Agents](/scheduled-agents) in the sidebar to create one with AgentOne or enter a schedule yourself, then search, edit, pause, resume, or delete it whenever you like. Schedules are shown in plain language, and chats from deleted scheduled agents remain available.

> Note: Scheduled agents run on your device, so if your device is off or asleep, they'll run once you turn it back on.

# Highlights

- **Talk to AgentOne while it's working.** You can now interrupt a response with a new message. The composer has a dedicated interrupt action and a configurable keyboard shortcut; the Stop button stops immediately.
- **Your chats are easier to navigate.** Optionally group sidebar chats into time periods, such as Recent and Last Week. The Message Preview Rail has a refreshed look and better previews that use the latest message text rather than the AI's reasoning. Branches also link back to their original chat.
- **A better home for extensions and tools.** Browse Extensions now has its own page, linked directly from the sidebar. Built-in tools have a dedicated Tools settings section, organized by what they do, with individual controls and descriptions.
- **More useful notifications.** Notifications can include a preview of AgentOne's answer and tell you when a chat needs tool approval or stops because of an error. Notifications on Linux now work in GNOME as well.
- **A smoother chat composer.** The input now uses the floating layout by default and fits narrow windows better. Unsent text is remembered separately for each chat while the app is open, and attachments take up less space in the composer.
- **Better keyboard shortcut setup.** The shortcut recorder has been redesigned, and shortcuts use the platform's usual modifier key: Command on macOS and Control on Windows and Linux.
- **Faster provider settings.** The provider list is now virtualized, making it easier to navigate when you have many providers.

# Miscellaneous Changes

- Fixed a bug that could replace existing attachments when adding more files.
- Starting a new chat no longer clears attachments unexpectedly.
- Fixed several chat search issues, including transient title results during content search, an overflow problem in the search dialog, and an edge case while results are loading. Search results are no longer grouped by time.
- Fixed cases where the chat sidebar could appear empty while loading. Search input and scroll fades in the sidebar have also been polished.
- Fixed chat scrolling issues, including a flickering Scroll to Bottom button and an unwanted jump as message content changes.
- Improved chat rendering performance by reducing unnecessary updates to messages, the sidebar, and the composer. Streaming updates are now throttled for smoother performance.
- Improved loading skeletons, the "Working" shimmer, and button animations throughout the app.
- Fixed an issue that allowed a message to be submitted before the selected model had finished loading.
- Improved scheduled agent setup and management, including clearer tool approval screens, more readable schedules, and fixes for runs scheduled close together.
- Scheduled agent operations now run off the main thread, so managing schedules won't freeze the interface.
- Fixed `agent-one://` links in Microsoft Store installs and several deep-link edge cases, including opening a new chat and submitting a scheduled prompt.
- Fixed local extensions that use a command to start failing to load on macOS.
- Fixed settings sync attempting to run after sign-out.
- Settings now opens to its default section instead of remembering the last tab you visited.
- Improved the app updater with an installation progress indicator and better keyboard focus when starting an update.
- Polished chat and settings UI details, including message action buttons, the Stop Text-to-Speech button, card borders, tooltips, and dropdown behavior.
- The app is now labeled **AgentOne Desktop** in the window title.
- AgentOne's logging has been simplified and improved, and usage analytics have been removed.
- Updated internal dependencies and cleaned up older code.
