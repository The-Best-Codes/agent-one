# Highlights

- Fixed a bug where chat cost tracking could use the wrong model after switching models and regenerating a response.
- Cost tracking has been rebuilt around per-message AI SDK usage metadata. Chat cost is now calculated from the generated messages themselves instead of stale chat-level totals.
- Extensions' tools now support customizable display labels for different operational states (loading, completion, error), so they're more user-friendly.

# Miscellaneous Changes

- Old beta chat cost-tracking data is not preserved in this release. Existing chats may show missing or reset cost usage until they generate new assistant messages.
- Cleaned up unused database columns related to the old chat-level cost tracking approach.
- Refactored loading UI with improved visual consistency across the application.
- Enhanced tool operation messaging for better visibility of tool states.
