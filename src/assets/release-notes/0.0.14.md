# Highlights

- Tools now return data to the AI model in a simpler format. This improves token usage for built-in extensions.
- AI-generated data tables have been reworked for a smoother, more responsive experience.
- In _Beta_: A new built-in extension, **Run commands**, allows the AI to run shell commands on your device. It requires your approval by default. Head to the Extensions tab in Settings, click `Advanced` on the `Built-in` extensions UI, and enable the new tool.

# Miscellaneous Changes

- New loading spinner style
- Empty text parts are no longer rendered, improving the UI for reasoning models
- Dependencies are up-to-date for a secure and fast experience
