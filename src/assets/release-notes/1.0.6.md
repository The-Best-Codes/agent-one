# Highlights

- We open-sourced [native-cron-rs](https://github.com/The-Best-Codes/native-cron-rs), our Rust crate powering OS-level cron job scheduling across macOS, Windows, and Linux. We're working on a new _Scheduled Agents_ feature which will use this crate to schedule agent executions on the OS level.
- There are now over 28,000 built-in extensions
- Fixed a bug on macOS that prompted for your password when opening the app
- On macOS and Linux, accordions now animate smoothly, matching the behavior on Windows
- The Web Search and Browse tools now emulate Chrome 149 instead of Chrome 137
- AgentOne is better at reading websites with large images

# Miscellaneous Changes

- Fixed the responsiveness of the tool approval mode UI
- Notifications are now enabled by default when the window is unfocused
- Fixed a few alignment issues in UI components
- Improved schema performance by upgrading to Zod 4.5
- Faster UI styling resolution powered by shadcn's `cn` package
- Updated internal packages
