# Highlights

- Drastically improved the performance of the "Run Command" tool. Previously, commands with long outputs or that updated frequently would cause the app to crash or lag. In this release, we've addressed those issues with better virtualization and output length limits.
- We've updated how long chats are handled (introduced in v0.0.18) so that it's now even more performant than before.
