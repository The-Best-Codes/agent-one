## AgentOne is now open source!

The entire codebase is now available under the AGPL-3.0 license on [GitHub](https://github.com/The-Best-Codes/agent-one). You can build it yourself, peek under the hood, or contribute. We'd appreciate a star on GitHub if you find it useful!

# Highlights

- **AgentOne is now available in 6 languages!** We added a full localization system, so you can now use the app in Spanish, French, German, Italian, and Russian in addition to English. You can switch languages at any time in the [Appearance Settings](/settings?tab=appearance#setting-language). Translations are AI-generated, so English remains the only language AgentOne is fully supported in, and switching to another language shows a heads-up first.
- **Resume interrupted responses.** When a response is interrupted by an error, you can now **resume it right where it left off** instead of retrying from scratch and losing the partial response.
- **7 new AI providers:** Api.Airforce, Hyper by Charm, Kenari, LLMTR, Qiniu, Sakana, and TokenRouter are now available out of the box. (We also removed the GitHub Models provider, as GitHub Models is deprecated.)
- **A whole new set of theme colors.** We expanded the accent color options from 7 to 17 (new colors like amber, teal, indigo, pink, and more) for both the primary color and the UI tint, with a new color picker popover to choose them. We also applied your roundness setting consistently across switches, sliders, avatars, and other UI elements.
- **Adaptive tooltips.** Tooltips across the app now open on touch and hold, so they work great on touch screens and desktop alike.
- **Safer extension installs.** Installing a "runs on your device" (stdio) extension now shows a clear **security warning**, and AgentOne checks whether the required runtime (like `npx` or `bunx`) is actually installed before you install it. Extensions that support it can now offer **multiple install methods** (beta).
- **More models and extensions than ever.** Over **10,000** models from 74 providers and **22,000** built-in extensions are now supported.

# Miscellaneous Changes

- Fixed the account section sometimes showing incorrect plan details. Plan names (Free, Pro, Ultra, Hyper) are now resolved properly from your subscription.
- Custom model overrides now support attachments.
- The "Extract Reasoning from Think Tags" setting is now disabled by default.
- Fixed scroll jumping around in virtualized chats.
- Fixed a bug where clicking a toast could accidentally close an open dialog. Toast theming also matches the app's theme now.
- Switches now use `rem` so they scale correctly with the app's text scale setting.
- The "describeNextTool" tool is excluded from tool approval requests.
- Fixed a UI bug in the tool approval flow when tools are missing before installing an extension, using a more stable button style to prevent layout shift.
- The chat model config drawer now renders as a popover that adapts to screen size, and its color matches the app theme.
- Fixed the theme toggle's position in the sidebar.
- The chat model selector was made more responsive for narrow windows.
- The AgentOne model directory was reordered and updated with the latest model data.
- Updated internal dependencies.
- Internally: global shortcuts are now desktop-only, an env var was added to disable the React compiler, the mobile scaffolding was re-initialized, and new app icons were added.
