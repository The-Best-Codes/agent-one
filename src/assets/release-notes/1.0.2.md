# Highlights

- Fixed a critical bug some users were experiencing where they could not log in to the desktop app correctly
- Support for hundreds of new models, including GLM 5.2, Fable 5 (by Anthropic), and more
- Memory usage improvements
- Removal of lazy loading that was causing bugs
- New Wikipedia search tool (beta), available as a built-in extension
- A new settings tool allows AgentOne to customize itself for you
- We now have over **13,000** built-in extensions! Behind the scenes, we're working on a new algorithm to sort and organize extensions. It will also prioritize first-party extensions, which will make the extension selection experience much better. Check out our [GitHub profile](https://github.com/AgentOne-Dev) and stay tuned for when we **open-source our extension registry**!

# Miscellaneous Changes

- Remove `stats.html` from default build output, reducing the size of the app
- Fix account section flickering in settings
- Fix flickering state of the provisioning section and skeleton in model select
- Added hover transition for the running executeCommand tool
- Fix race condition in MCP tool cleanup; loading states no longer rely on all tools finishing loading
- Better macOS support
- Improved the memory tool and overall prompt experience
