# Mention files and skills in the message box

The message box now understands what you're pointing at. Mentions show up as chips in your message, both while you type and in the chat afterward.

- **@ to mention files.** In a project with a folder, type `@` to search its files and folders and mention one in your message. AgentOne gets the file's path and can open it with its tools.
- **/ to use a skill.** Type `/` to search your skills and pick one for AgentOne to follow.
- **Chats as mentions.** Dragging a chat from the sidebar into the message box now adds it as a chip instead of a file.
- **Turn them off.** You can turn off **@ Mention Suggestions** and **/ Skill Suggestions** separately in [Chat settings](/settings#setting-file-mention-completions).

# A new way to attach files

Attachments have been rebuilt. Instead of sending a copy of each file to the model, AgentOne now gets the file's location on your computer and opens it with its tools, so it can work with any kind of file, including large ones.

- **Attachments live in your message.** Attached files show up as chips right where you put them. Click one to preview it, or open it in its default app.
- **Analyze files.** When AgentOne needs to know what's in a file it can't read itself, like an image, video, audio file, or PDF, it can send the file to another model and ask about it. This uses the chat's own model by default, and you can pick a different model for each type of file in [Attachments settings](/settings#setting-file-analysis-enabled), or turn it off.
- Attaching files needs tools to be turned on, since AgentOne uses them to open the files.

# Miscellaneous Changes

- Fixed links not opening on macOS.
- Fixed token usage not showing up in the chat usage indicator for Ollama and other local, custom, and OpenAI-compatible providers.
- The memory tool now tells AgentOne when an entry is skipped because it's already saved or memory is full, and how much of memory is used.
- AgentOne is better at updating scheduled agents and knows more about how AgentOne works, like where to find settings and how tool approvals work.
- Chat titles and message previews show mentions as plain names instead of links.
- Updated app dependencies.
