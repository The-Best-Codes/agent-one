# Highlights

- **New:** You can now customize the main chat page with a background image!
- Added the OpenCode Zen provider, a curated set of models tested for coding agents.
- Added about 1000 new extensions.

# Miscellaneous Changes

- Added provider logos to the provider settings list and model selector so providers are easier to identify while choosing models.
- Added **Extract Reasoning from Think Tags** setting (Chats > Streaming Experience). When enabled (the default), `<think>...</think>` blocks emitted by models like DeepSeek are automatically stripped from the response text and displayed as a collapsible reasoning section in the chat UI.
- Fixed the Extensions section not taking up the full height of the UI.
- Fixed some border clipping issues in the UI.
- Improved the memory tool so that it works more consistently across different model providers.
- Updated internal dependencies for a more performant and secure experience.
- Fixed some accessibility issues in the keyboard shortcuts UI.
