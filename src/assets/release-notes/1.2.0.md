# Organize your work with Projects

**Projects** group related chats and give them shared instructions. Create one from the sidebar, give it a name, and AgentOne keeps its chats together under it.

- **Shared instructions.** Anything you write in a project's instructions applies to every chat in it, so you don't have to repeat yourself.
- **Work inside a folder.** Pick a folder for the project, and its chats work inside that folder. Choosing a folder also names the project after it if you haven't named it yet.
- **Separate memory.** Turn on **Separate memory** to keep a project's memory and chats apart from everything else. AgentOne keeps a separate memory for the project, and the Chat History tools can only find the project's chats from inside it.
- **Move chats around.** Drag a chat onto a project in the sidebar, or use **Move to Project** in the chat's menu. When you start a new chat, pick its project next to the message box.
- **Delete safely.** Deleting a project asks you to confirm and lets you choose whether to delete its chats too.

# Auto mode

Tool approvals are a balance: ask too often and you're clicking "Approve" all day, ask too rarely and AgentOne might do something you didn't want. **Auto mode** handles this for you. Before AgentOne runs a tool that would need your approval, a model checks it against what you asked for. Safe steps run right away, risky ones are blocked, and you're asked only when it can't tell.

- **Auto is the new default tool behavior.** You can still switch any chat to **Per-tool approval**, **Always ask**, or **YOLO** in the model configuration next to the model selector.
- **It only sees what you asked.** The check looks at your messages and the tools AgentOne has called, not tool results or web pages, so text in a file or website can't talk it into approving something.
- **Blocked actions show why.** When auto mode blocks a tool, the chat shows a short reason and AgentOne tries a different approach. If it blocks several actions in a row, it hands the decision back to you.
- **Make it yours.** Choose which model does the checking and add your own rules, like "Installing npm packages is fine" or "Never push to git," in [Auto Mode settings](/settings#setting-auto-mode).

# Skills

AgentOne can now use **skills**: folders of instructions, examples, and scripts for a specific kind of task. When a task matches a skill, AgentOne reads it first and follows it.

- AgentOne looks for skills in `~/.agents/skills` and `~/.claude/skills` by default, so skills you already use with other agents work right away. Change the folders in [Skills settings](/settings#setting-global-skills-folders).
- Projects with a folder also look in the project's `.agents/skills` and `.claude/skills`, and you can pick each project's skill folders yourself.
- Skills are treated as guidance, not as messages from you. If a skill asks for something that goes against what you asked, AgentOne tells you instead of doing it.

# Instruction files

Point AgentOne at instruction files like `AGENTS.md` and it reads them at the start of every chat. `~/AGENTS.md` is used by default, and you can add or remove files in [Instruction files settings](/settings#setting-global-agents-files). Projects with a folder also read the `AGENTS.md` in that folder, and you can choose each project's files yourself.

# Simpler tool settings

[Tools settings](/settings#section-tools) have been reorganized into plain switches grouped by what they do: **Web**, **Files**, **System**, and **Computer Use**. Each group has an "Allow" switch and, where it matters, an "Ask before" switch. Settings for memory, chat history, settings changes, and scheduled agents moved next to the features they control.

Tools that only look things up, like reading files, searching the web, searching past chats, and using memory, no longer ask for approval. Subagents also no longer ask, since the tools they use still follow your approval settings.

# Computer Use comes to Linux

Computer Use now works on Linux, so AgentOne can see and use your apps there too. It's been rebuilt on a new engine that's faster and more reliable on every platform, and it finds your installed apps without listing duplicates.

# AgentOne can report problems

When something goes wrong on AgentOne's side, like a tool that keeps failing or a capability AgentOne is missing, it can now send a short report to the AgentOne developers so we can fix it. It asks for your approval before sending each report. You can turn this off in [Tools settings](/settings#setting-allow-feedback).

# Better on small windows

- The message box no longer overlaps the project picker and model selector in narrow windows.
- Tool approval cards no longer overflow narrow chats.
- Long chat titles no longer squash the chat status indicators in the sidebar.
- The search and release notes dialogs now fit smaller windows.
- Fixed more icons shrinking and text overflowing in tight spaces.
