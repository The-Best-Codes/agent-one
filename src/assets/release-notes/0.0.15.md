# Highlights

- Bug fix: The **Run commands** tool now properly collects the output of commands that run very fast (e.g., `ls`, `pwd`, and similar commands).
- **Reasoning** sections of the AI response are now nicely formatted (they respect your Markdown rendering settings). If your AI model has Markdown reasoning output, it will now be smoothly rendered in the "Reasoning" section of its response.
- The terminal now uses a default, darker theme for better readability.
- **You can now search chat contents, not just chat titles!** This is in beta while we experiment with the search options and get the performance right. For debugging purposes, you'll see a "Raw FTS5 Search" option in the search dropdown.

# Miscellaneous Changes

- Added new models from various providers
- Updated the list of extensions with lots of new items
- Dependencies are up-to-date for a secure and fast experience
