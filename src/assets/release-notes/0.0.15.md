# Highlights

- Bug fix: The **Run commands** tool now properly collects the output of commands that run very fast (e.g., `ls`, `pwd`, and similar commands).
- Bug fix: Tools and extensions that required approval now properly exit when you press the stop button. Before, attempting to stop them would fail.
- The disruptive "Performance Alert" section in the middle of AI responses has been removed.
- Custom extensions (MCP servers) now support [**tool pagination**](https://modelcontextprotocol.io/specification/2025-11-25/server/utilities/pagination).
- **Reasoning** sections of the AI response are now nicely formatted (they respect your Markdown rendering settings). If your AI model has Markdown reasoning output, it will now be smoothly rendered in the "Reasoning" section of its response.
- The terminal now uses a default, darker theme for better readability.
- **You can now search chat contents, not just chat titles!** This is in beta while we experiment with the search options and get the performance right. For debugging purposes, you'll see a "Raw FTS5 Search" option in the search dropdown.
- When the app starts, the database is now automatically optimized. This means your chats use less storage space on your device and searching is faster.

# Miscellaneous Changes

- Added new models from various providers
- Updated the list of extensions with lots of new items
- Dependencies are up-to-date for a secure and fast experience
- Switched **Run commands** UI to a simpler, more performant rendering method
- Extensions that support tool titles will now render more user-friendly tool names when their tools are running
- Improve performance of database writes
- Fixed a bug in some extensions where commands with quotes and escape characters weren't processed correctly.
- Fixed item overlap is chat selection UI.
