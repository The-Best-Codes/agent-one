# AgentOne

## Prerequisites

- Node.js
- npm
- Rust & Tauri https://tauri.app/start/prerequisites/

## Installation

Clone the repository using the following command:

```bash
git clone https://github.com/The-Best-Codes/agent-one.git
```

Install dependencies:

```bash
cd agent-one
npm install
```

Run the application:

```bash
npm run tauri dev
```
